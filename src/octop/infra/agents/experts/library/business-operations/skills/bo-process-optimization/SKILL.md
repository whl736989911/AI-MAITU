# Process improvement

1. State the observed process and evidence boundary.
2. Locate friction only where the materials support it; distinguish observed delay or rework from hypothesized cause.
3. Frame each intervention as a proposal, with intended effect, prerequisites, accountable role and target timing clearly marked as proposed unless supplied as fact.
4. Define a baseline and follow-up measure using the same event definitions, numerator, denominator, units, and period. Identify missing data rather than substituting an unrelated proxy.
5. Do not imply the proposal is approved, implemented, or successful.
