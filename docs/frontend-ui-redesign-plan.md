# 前端界面调整：原项目 UI 与紧凑布局

## 当前决定

沿用原项目的页面、组件、配色、圆角和明暗主题，不再将此前的工作台重设计或独立演示稿迁入正式界面。此次只整合资源设置，并把纵向留白压缩到很小；不更换业务接口或权限规则。

## 专家与功能配置

- 专家页面：在对应专家上点击「配置」，在该专家页面内维护原个性化面板；配置始终绑定明确的专家 ID，不跟随聊天全局 Agent 选择意外切换。
- 功能页面：在对应功能上点击「配置」，在该功能页面内维护工作流、业务数据及原个性化面板。
- 继续复用技能、子智能体、工具、插件、人格、记忆、通道等已有面板。功能原有的人设文件、工作流和业务数据入口保留，不为统一布局改变其业务含义。
- 不再提供独立的个性化页面和全局资源配置入口；聊天、卡片、表格及其他原快捷入口进入对应资源页。
- 启停、重载、编辑、删除、聊天、工作区和适用的发布操作仍可达；不能通过删除操作或隐藏权限状态来压缩界面。
- 专家与功能列表沿用原卡片/表格组件，而不是此前设计的全宽资源行。

## 纵向密度

采用原主题叠加最小的间距调整，不通过换色、扁平化装饰或缩小正文制造变化。

| 部位 | 调整目标 |
|---|---|
| 页面、标题与分区 | 上下内距和相邻区块间距约 4–6px，移除固定的高标题空白 |
| 卡片 | 上下内距约 4–8px；专家与功能卡片移除固定最小高度和空描述占位，保留原有横向排布与样式 |
| 表单 | 表单项上下间距约 6–8px，帮助和校验信息就近显示 |
| 表格 | 单元格上下内距约 4px，保留列对齐及局部横向滚动 |
| 标签页与过程组件 | 收紧标签、折叠头、工具与思考块的上下内距 |
| 聊天 | 消息间距约 6–8px、段落间距约 2–4px；用户靠右，助手靠左 |

正文保持可读，不把间距需求变成小字。头像保持清晰完整；手机保留合理触控区域。登录、初始化、邀请等公开页面不套用登录后密度调整。

## 权限与状态约束

- 模块权限、资源管理权和各面板的读写策略分别校验；能打开资源页不代表能修改全部设置。
- 功能作者、企业管理员和普通调用者沿用原有工作流、共享记忆和私人记忆规则。
- 未授权资源不能退回全局 Agent 后显示另一资源的编辑表单；权限加载失败时不开放可提交编辑。
- 在同一资源内切换设置仍保留已挂载面板及其状态；不能因样式调整重建运行会话或丢弃聊天草稿。

此前独立演示入口保留供对照，不是本次正式界面的实现入口。本地正式界面使用现有真实后端，不以演示样例替代功能验收。

- 实测标题与内容间距 4px、表格单元格上下内距 4px、聊天段落上下外距 3px。390px 手机视口无整页横向溢出，用户菜单仍在左侧导航底部。
